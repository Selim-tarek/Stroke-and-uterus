### A03a_algorithm

Outcome algorithm, from the Codebook notes and the scripts

| step | rule |
|---|---|
| Source | Problem List + Diagnosis extracts, any date in the record, then positive brain-imaging reports (Codebook: stroke_any). Code lists are in the workbook sheet stroke_outcome; the raw stroke diagnosis extracts are not in data/. |
| Event types | stroke_type from the most specific code: 1 ischemic, 2 ICH, 3 SAH, 4 TIA, 5 CVT, 9 unspecified (188 women with >1 type, flagged in notes). |
| TIA | Excluded from the outcome (R/13_anchor_design.R:55), but a TIA ENDS follow-up for stroke (R/13:52, censored). |
| Imaging-only cases | Included if infarct on imaging without a code, including chronic/incidental infarcts and hedged wording (Codebook stroke_any note). Dated by the scan. |
| Event date | Earliest coded diagnosis or problem date (Codebook stroke_date); not chart-verified. Acute, history and sequela codes all count. |
| Timing | Incident if stroke_date > anchor (R/13:50); stroke on or before anchor, or undated, excluded. |
| One record per woman | Single stroke_any/stroke_type/stroke_date per woman, so recurrent events cannot be counted and the first event is the earliest code of any kind. |
| Not done | No chart adjudication; no source-document review was possible in this audit (no notes or charts in the project). |

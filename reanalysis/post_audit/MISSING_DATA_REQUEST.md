# Missing-data request

Every item below was confirmed absent from the project by `post_audit/R/P01_inventory.R` (P01a–P01c). Present data: the master file, `stroke.xlsx`, diagnosis extracts 22–31, three encounter files with one row per patient, six CBC-only lab extracts, and medication file 9 (iron and spironolactone only).

**Linkage for every item:** link by the clinic number used in the existing extracts, to the existing `study_id` crosswalk. All dates should be calendar dates (day resolution) or better. Use the period 1990-01-01 to 2026-09-27 unless stated otherwise, so that pre-anchor history is visible.

| # | Request | Required fields | Why it is needed | Analysis it enables | Defensible partial analysis without it? |
|---|---|---|---|---|---|
| 1 | **Dated diagnosis records** for hypertension, diabetes (types 1 and 2), dyslipidemia, CAD, migraine (with or without aura), atrial fibrillation, heart failure, VTE and thrombophilia | clinic number; code system; code; description; **diagnosis date**; **problem-list onset date and entry date**; encounter type (inpatient, ED, outpatient); diagnosis position (principal or secondary) | Migraine and diabetes have no ascertainment date. Hypertension and CAD dates rest only on a Codebook statement. These are the largest sources of possible information leakage. | Re-derive every predictor strictly at or before the anchor; a baseline-only refit including migraine and diabetes; the decisive test of whether the current model's extra discrimination (temporal ΔC 0.066 over baseline-only) is real | Partly: the baseline-only models C3 and C4 (P05, P06) exclude migraine, diabetes and estrogen |
| 2 | **Medication orders, prescriptions and dispensing** for all estrogen-containing products (combined oral contraceptives, patch, ring, menopausal hormone therapy) | clinic number; medication name and generic; RxNorm or NDC; route; **order start and end dates**; dispense dates; status | The current estrogen variable uses a window with no end date and includes non-therapeutic products (F-18 fluoroestradiol, IV conjugated estrogens) | A baseline estrogen exposure (current use at the anchor); an estrogen-specific analysis | No. Estrogen must stay out of the model. |
| 3 | **Raw stroke outcome extract** | clinic number; every cerebrovascular code (ischemic, ICH, SAH, CVT, unspecified, TIA, history and sequela); **date of each code**; encounter type and admission date; principal or secondary position; problem-list onset date | Only the earliest code date and a list of code kinds are in the project, so it can't be determined which code came first, or whether an event is acute, recurrent or historical | An outcome defined as the first *acute inpatient or ED* stroke code; TIA as a non-terminal event; detection of misdated history codes | Partly: the acute-code and >30-day sensitivity outcomes (P03) |
